## 지표 읽는 기준

- VU는 동시 가상 사용자 수이며, 응답시간 단위는 ms다. TPS와 성공 요청/초는 각 표의 집계 방식에 따른 값이다.
- 작업 1~4의 시간·TPS는 기존 nGrinder 집계다. 작업 4의 p95는 **2초 구간 평균의 p95**이며 개별 요청 p95가 아니다.
- 작업 6~8은 개별 요청 CSV를 검증했다. 작업 7·8의 지연과 처리량은 반복별 지표의 중앙값이며, 성공 요청의 지연과 오류 건수를 분리한다.
- 작업 8의 비교 지표는 실행마다 동일한 140초 구간을 사용한다. 전체 실행 건수와 비교 구간 건수는 구분한다.
- 스크립트·회원·SQL 로그·워밍업·실행 길이·공유 호스트 상태가 달라 작업 사이의 숫자를 직접 연결해 성능 개선률을 계산하지 않는다.
- 과거 seed 크기별 짧은 탐색은 존재하지만, 최근 상세 대조 측정은 H2 seed 1,000으로 고정했다. 운영 PostgreSQL 용량이나 운영 SLO를 확정한 결과는 아니다.
